MultiCalc Universal is an ultra-lightweight, single-file web application that combines advanced mathematical evaluation, interactive physics formula solvers, a computer science bitwise matrix, a universal unit converter, and financial/health tools—all wrapped in a dark cosmic fluid canvas aesthetic.

---

## ✨ Key Features

### ⚛️ Physics & Quantum Constants Suite (Electric Violet Glow)
* **10 Fundamental Physics Constants:** Instant insertion of $c, g, h, G, k_B, e^-, N_A, R, \varepsilon_0, \mu_0$.
* **Interactive Formula Solvers:** Kinetic Energy ($E_k = \frac{1}{2}mv^2$), Newton's 2nd Law ($F = ma$), and Ohm's Law ($V = IR$).
* **Scientific Trigonometry & Logarithms:** Degree/Radian mode toggle, logarithms ($\ln$, $\log_{10}$), powers, square roots, and factorials.

### 💻 Computer Science & Low-Level Suite
* **32-Bit Interactive Bitwise Register:** Toggle individual bits in real-time with synchronized updating across Decimal, Hexadecimal, and Binary representations.
* **Multi-Base Converter:** Real-time conversion across DEC, HEX, BIN, and OCT formats.
* **CIDR Subnet Calculator:** Computes subnet masks, network IPs, and total usable host counts from any CIDR notation (e.g., `192.168.1.1/24`).

### 📏 14-Category Universal Unit Converter
* **Smart Natural Language Parser:** Type queries like `"10 km to miles"` or `"100 f to c"` for instant evaluation.
* **14 Unit Categories:** Length, Mass, Temperature, Volume, Area, Speed, Time, Data Storage, Data Transfer, Pressure, Energy, Power, Angle, and Fuel Economy.
* **Live Unit Grid:** View full conversion matrices across all category units simultaneously.

### 💰 Financial & Health Tools
* **Loan EMI Visualizer:** Monthly payment breakdown based on principal, interest rate, and tenure.
* **Tip & Bill Splitter:** Per-person bill calculations with custom tip percentages.
* **BMI Health Calculator:** Body Mass Index analysis with health weight classifications.

### 🔒 Access Control & Code Protection
* **Local Sign-In Gate:** Session-persistent gate via `localStorage`. Keeps users authenticated locally without storing or transmitting personal data externally.
* **Client-Side Code Security:** Context menu (right-click) suppression, developer tools keyboard shortcut blocking (`F12`, `Ctrl+Shift+I/J/C`, `Ctrl+U`, `Ctrl+S`), text selection protection, and anti-debugging execution loops.
